  Syntaxe SIMAC prise en charge
  

    
Référence des syntaxes reconnues par l’interpréteur, avec des exemples à recopier dans l’éditeur. Les mots-clés ne sont pas sensibles aux majuscules/minuscules. Les instructions ordinaires se terminent par ; ; les mots de structure sont écrits seuls sur leur ligne.

    
Astuce : clique sur « Exemple » pour charger un programme de démonstration, puis sur « Exécuter ».

  

  

    

      
1. Structure d’un algorithme

      
Le nom de l’algorithme est facultatif. Le programme doit contenir Debut et se terminer par Fin.

      
Algorithme Bonjour ;
Debut
    Ecrire("Bonjour SIMAC !");
Fin.

    

    

      
2. Variables et constantes

      
Déclare les variables dans Variable. Les constantes peuvent être déclarées avec ou sans type explicite.

      
Constante
    AGE_MAJEUR = 18 ;
    PI : Reel = 3.14 ;
Variable
    age : Entier ;
    nom : Chaine ;
    moyenne : Reel ;
    actif : Booleen ;
Debut
    age <- 20 ;
    nom <- "Awa" ;
    moyenne <- 15.5 ;
    actif <- Vrai ;
    Ecrire(nom, age) ;
Fin.

      
Types reconnus : Entier, Reel, Texte, Chaine, Caractere, Booleen (avec variantes accentuées pour certains noms).

    

    

      
3. Affectation et calculs

      
Les trois écritures d’affectation acceptées sont <-, ← et :=.

      
Variable
    a, b, resultat : Entier ;
Debut
    a <- 12 ;
    b := 5 ;
    resultat <- a + b * 2 ;
    Ecrire(resultat) ;
Fin.

      
Opérations : +, -, *, /, ^, %, DIV, MOD. % et MOD calculent le reste ; DIV la division entière.

    

    

      
4. Lire et écrire

      
Lire(...) attend la saisie dans le terminal. Ecrire(...), Écrire(...) et Afficher(...) affichent un résultat.

      
Variable
    prenom : Chaine ;
    age : Entier ;
Debut
    Ecrire("Ton prenom : ") ;
    Lire(prenom) ;
    Ecrire("Ton age : ") ;
    Lire(age) ;
    Ecrire("Bonjour", prenom) ;
    Ecrire("Age :", age) ;
Fin.

    

    

      
5. Conditions Si / Sinon

      
Une condition se termine par Alors, puis le bloc se ferme avec FinSi.

      
Variable
    note : Reel ;
Debut
    Ecrire("Saisis ta note : ") ;
    Lire(note) ;
    Si note >= 10 Alors
        Ecrire("Admis") ;
    Sinon
        Ecrire("A revoir") ;
    FinSi ;
Fin.

      
Comparaisons : =, <>, <, >, <=, >=. Logique : ET, OU, NON.

    

    

      
6. Choix SelonQue

      
Chaque branche commence par Cas valeur :. La branche facultative Sinon traite les autres valeurs.

      
Variable
    choix : Entier ;
Debut
    Ecrire("Choisis une option (1 = Accueil, 2 = Cours) : ") ;
    Lire(choix) ;
    SelonQue choix Vaut
        Cas 1 : Ecrire("Accueil") ;
        Cas 2 : Ecrire("Cours") ;
        Sinon : Ecrire("Choix inconnu") ;
    FinSelonQue ;
Fin.

    

    

      
7. Boucle Pour

      
Le compteur doit être déclaré. Le pas est facultatif et vaut 1 par défaut.

      
Variable
    i : Entier ;
Debut
    Pour i <- 1 à 5 Faire
        Ecrire("Tour", i) ;
    FinPour ;
Fin.

      
Avec un pas personnalisé : Pour i <- 2 à 10 Pas 2 Faire.

    

    

      
8. Boucles TantQue et Répéter

      
Variable
    i : Entier ;
Debut
    i <- 1 ;
    TantQue i <= 3 Faire
        Ecrire(i) ;
        i <- i + 1 ;
    FinTantQue ;

    Repeter
        i <- i - 1 ;
    Jusqu'à i = 0 ;
Fin.

      
TantQue ... Faire teste avant le bloc. Repeter ... Jusqu'à exécute le bloc au moins une fois.

    

    

      
9. Tableaux à une ou plusieurs dimensions

      
Les bornes sont inclusives. Les indices doivent rester dans les bornes déclarées.

      
Variable
    T : Tableau[1..4] d'entier ;
    M : Tableau[1..2, 1..3] de Reel ;
    i : Entier ;
Debut
    T[1] <- 10 ;
    T[2] <- 20 ;
    M[1,2] <- 4.5 ;
    Ecrire(T[1], M[1,2]) ;
    Pour i <- 1 à 4 Faire
        Ecrire(T[i]) ;
    FinPour ;
Fin.

      
Les tableaux sont initialisés avec la valeur par défaut de leur type. Les indices sont écrits entre crochets : T[i], M[i,j].

    

    

      
10. Fonctions intégrées

      
Variable
    x : Reel ;
    n : Entier ;
    texte : Chaine ;
Debut
    x <- Racine(81) ;
    n <- Entier(-7.8) ;
    texte <- "SIMAC" ;
    Ecrire(x) ;
    Ecrire(Abs(-12)) ;
    Ecrire(Longueur(texte)) ;
Fin.
